# TRIAID

TRIAID is an open research framework for modeling dynamic states, transitions, and intervention-relevant structure in complex systems.

## Independent replication challenge

The frozen constructed-domain C7 replication challenge is now open in [replication/](replication/README.md).

The challenge is deliberately falsifiable. External teams are asked either to reproduce the author artifacts or, for strict constructed-level C7, independently reimplement the frozen specification and report all ten controlling gates without post-result retuning.

Current boundary: C7 remains open until an independent external team executes the frozen relation. Real-world efficacy, planner superiority, clinical efficacy, and universal research acceleration are not claimed.
