# TRIAID Open Validation Program v1.0

This is an additive repository-governance layer. It does not alter TRIAID Paper 1 v1.0.0 or its frozen scientific files.

Included:

- `OPEN_VALIDATION.md` — three-track validation program and evidence ladder;
- `CONTRIBUTING.md` — contributor rules and frozen-target discipline;
- `validation/RESULT_TEMPLATE.json` — structured result record;
- `validation/validate_result.py` — standard-library structural validator;
- `validation/example_result.json` — engineering smoke example;
- GitHub issue forms for REPRODUCE, CHALLENGE, and VALIDATE;
- pull-request template;
- additive GitHub Actions validation workflow.

The program deliberately accepts negative results, stronger baselines, and falsification attempts. A contribution cannot upgrade its evidence class by wording alone.
